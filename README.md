# Sensorless FOC using I/f startup method and Sliding mode observer

## Overview:
The following repository contains a firmware implementing bldc-motor control using an STMicroelectronics- develpment kit and motor driver expansion board. The firmware uses the I/f startup strategy and a sliding-mode observer.

## Hardware:
- X-NUCLEO-IHM08M1
- NUCLEO-G491RE
- Flyroun 5010 360KV bldc motor
- 16V supply voltage
